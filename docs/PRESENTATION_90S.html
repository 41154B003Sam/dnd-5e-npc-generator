❌ 現有開卡工具的三大瓶頸

  • 為 PC 設計而非為故事服務：強制套用死板冒險者規則，缺乏劇本靈活度。
  • 千篇一律的刻板套路：戰士必穿板甲拿劍盾、法師必握魔杖，毫無故事驚喜。
  • 數值寫死缺乏彈性：無法即時配合地下城主 (DM) 現場劇本動態調整。
  • 多頁試算表翻找不易：多達 10~19 頁工作表，跑團緊急查閱極易混亂。

💡 我們的核心破局思維

  • 故事與規則徹底解耦：市井生活身分（老農夫）＋ 專業戰鬥底層（資深戰士）。
  • 非典型生活武器法器：鋼齒長草耙能當武器 (1d8/1d10)、老煙斗吞吐青煙施法。
  • 真隨機 4d6dl1 靈活建議池：原始骰面透明展示，保留 DM 自主配置權。
  • 直向快速掃視角色卡：3 秒一覽戰鬥數值、特長與劇本線索，專為跑團主持打造。

💡 核心設計理念
哲學與思維

🎯 規則保護玩家公平，但 NPC 是 DM 推進劇情的資產

🌾 1. 身分與戰力解耦

傳統 D&D 認為「農夫就是農夫」。本系統打破常規：外貌可以是種田老漢或古董店老闆，但戰鬥底層完全能套用 Lv.5 甚至 Lv.14 的專業戰士或法師模板。

🔨 2. 生活武器與法器動態映射

不強迫手持標準劍杖。日常所見的鋼齒長草耙、剁骨砍刀、挖墳鐵鎬、符文老煙斗、黃銅算盤，皆能精確映射至 5E 規則傷害骰與施法專注特性。

🌿 3. 拒絕強加異能：支援「常規凡人」

不是每個人都需要超自然神力。關鍵字支援輸入「無」，可隨心生成純粹依憑凡人歷練與手中熟稔工具立足的純樸百姓、商販與工匠。

🏗️ 模組化分層架構 ＋ 零外部套件相依

🧩 系統三層架構

  • 雙平台使用者介面層：
    • 原生桌面視窗 (gui.py)：Tkinter 深色高對比，免開黑窗。
    • 免安裝網頁版 (index.html)：純前端自包含，離線雙擊即開。
  • 核心推論生成層 (dnd_npc_generator)：
    • 4d6dl1 實擲引擎 (roller.py)
    • 繁體中文 5E 規則字典庫 (database.py)
    • 語意與規則解析器 (generator.py)
  • 多格式資料匯出層 (exporter.py)：
    • 直向 Markdown 角色卡 ｜ 通用 CSV ｜ 標準 JSON

🛡️ 純標準庫零相依（Zero Dependency）

  • 極致純淨：全系統採用 Python 3.12 內建標準庫（tkinter, json, csv, http.server, random）開發。
  • 免安裝任何套件：無需 pip install 任何第三方模組，隨處開箱即用。
  • 極速生成：平均生成時間僅需 0.01 ~ 0.08 秒，瞬間響應跑團需求。
  • 絕對資安合規：零 API Key、零通行碼、零敏感網址，完全離線運作。

⚙️ 演算法與規則機制
核心演算法

⚡ 三大關鍵演算法：嚴謹體系與敘事彈性並存

🎲 1. 4d6dl1 實擲建議演算法

以 [random.randint(1, 6) for _ in range(4)] 擲骰並取前 3 高總和，產出 6 組原始點數池；依據職業核心機制（如戰士重力量體質、法師重智力）提供最優優先權建議與種族加值候選清單，不硬編碼。

📜 2. 語意等級解析與狀態封印

自然語言等級解析器支援輸入「大魔導師」自動對應 Lv.13~14、「老兵」對應 Lv.5；當識別出「封印 / 詛咒」時，自動標記高環法術位鎖定警示，並將預估挑戰等級 (CR) 精準下修。

⚔️ 3. 語意生活裝備映射矩陣

以正則比對自動識別劇本文字：
• 提及「草耙、耙」➜ 鋼齒長草耙 (1d8/1d10 穿刺)
• 提及「煙斗、茶杯、算盤」➜ 奧術專注法器
• 提及「鐵鎬、鏟」➜ 重型挖墳武器 (1d8 穿刺)

捨棄脆弱且容易損毀公式與繪圖的專有格式，改採全球通用的純淨資料交換標準：匯出的 CSV 可在 Microsoft Excel 或 Google Sheets 中完美開啟，絕不跑版或跳出毀損警告。

💾 3. 標準 JSON 結構資料

產出完整的結構化 NPC 物件，嚴格包含六大屬性、推薦值、裝備清單與自訂標籤，完全相容 Roll20 與 Foundry VTT 數位線上跑團平台之 Actor 規格匯入。
