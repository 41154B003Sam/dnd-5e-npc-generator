D&D 5E 劇情導向非典型 NPC 智慧生成系統

讓每一個路人角色，都擁有令人過目不忘的故事靈魂與嚴謹戰力數據

❌ 現有工具三大致命痛點

  • 為 PC 設計而非 NPC：強制綁定死板冒險者規則，缺乏劇情靈活度。
  • 千篇一律的刻板印象：戰士必拿劍盾、法師必握法杖，毫無故事驚喜。
  • 數值寫死缺乏彈性：無法即時配合地下城主 (DM) 現場劇本動態調整。

💡 我們的核心破局思維

  • 故事與規則徹底解耦：市井身分（農夫）＋ 戰鬥底層（戰士模板）。
  • 非典型武器與生活法器：長草耙能當武器 (1d8/1d10)、老煙斗能施法。
  • 真隨機 4d6dl1 建議池：原始骰面透明展示，保留 DM 自由調配權。

⚡ 四大突破性機制：為劇本敘事量身打造

🎲 1. 4d6dl1 實擲池 ＋ 優先權建議

真實擲出 4 顆骰子捨去最低點數，保留 6 組原始點數池，並依職業（戰士重視力量、法師重視智力）提供最佳化配置建議與種族加值清單，絕不硬編碼寫死數值。

🌾 2. 非典型生活武器與故事道具

自動語意辨識劇本生活物品：
• 鋼齒長草耙 ➜ 1d8 (雙手 1d10) 多用穿刺武器
• 符文老煙斗 / 算盤 / 懷錶 ➜ 奧術施法道具

📜 3. 語意等級解析與狀態封印

支援關鍵字等級映射（「老兵」➜ Lv.5，「大魔導師」➜ Lv.14）；輸入「封印狀態」自動啟動警告標籤並鎖定高階法術環位，完美符合被貶或負傷的強者設定。

🛡️ 4. 零外部依賴 ＋ 離線極致安全

採用 Python 3.12 純標準庫（JSON/CSV/Argparse）開發，無需安裝龐大第三方套件，0.08 秒極速生成，並針對 Windows 終端機 UTF-8 與 Emoji 做了完美編碼容錯。

📜 DM 專屬直向預覽卡 (Vertical Card)

告別在多個分頁來回切換的惡夢！本系統將「身分外貌 ➜ 骰點建議 ➜ 非典型武器 ➜ 特長與法術位 ➜ 劇本線索」濃縮為垂直條列，DM 只要 3 秒就能掌握全貌。

📑 官方 10 頁 Excel 模板無縫相容

系統內建 get_flattened_dict_for_excel() 轉換模組，嚴格對齊專業術語（體魄 CON、察言觀色 Insight、被動觀察 Perception、契術師 Warlock），支援一鍵輸出 CSV / 結構化資料。
