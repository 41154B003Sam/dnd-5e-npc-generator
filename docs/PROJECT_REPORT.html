專題報告：D&D 5E 劇情導向非典型 NPC 智慧生成系統

專案名稱：TRPG Story-Driven Unorthodox NPC Generator (D&D 5E 劇情導向非典型 NPC 智慧生成系統)

開源倉儲 (GitHub)：https://github.com/41154B003Sam/dnd-5e-npc-generator

資安合規聲明：本專案程式碼、截圖與報告內絕無任何私密金鑰、通行碼或 /exec 敏感網址；倉儲名稱未包含個人姓名學號。

一、 做什麼 (What)

本專題是一套專為桌上角色扮演遊戲（TRPG，以《龍與地下城》Dungeons & Dragons 5E 規則為核心）量身打造的「劇情導向非典型 NPC 智慧生成系統」。

1. 核心背景與要解決的問題

在 TRPG 跑團過程中，地下城主（DM / Storyteller）必須頻繁生成非玩家角色（NPC）。但現有開卡工具（如 D&D Beyond、5eTools）普遍存在三大瓶頸：

  • 為玩家 (PC) 設計而非為故事 (NPC) 服務：強行要求合規的屬性分配、嚴格負重與技能樹，導致備戰手續繁瑣且脫離當前劇本。
  • 千篇一律的刻板套路：戰士必定穿全身板甲拿大劍，法師必定手持魔杖。然而在精彩的劇本中，往往需要「表面是平凡老農、隨身拿著鋼齒長草耙，真實身分卻是退隱禁衛隊長的資深戰士」，或是「不依靠制式魔杖，而是抽著刻印符文的石楠木老煙斗施法的大魔導師」。
  • 數值寫死缺乏彈性：傳統卡片把屬性數值釘死，剝奪了 DM 因應戰況動態微調的彈性。

2. 系統核心功能

  • 真隨機 4d6dl1 屬性建議池：真實模擬 4 顆六面骰捨去最低值的實擲池，提供依職業優先權推薦的基礎點數，並附帶種族加值候選清單，絕不強制寫死數值。
  • 故事身分與戰鬥底層解耦：生活身分（如麥農、商人、工匠）與戰鬥底層（戰士、法師模板）完全獨立，賦予角色鮮明的故事反差。
  • 非典型武器與生活法器動態映射：自動將劇本中的生活道具（如長草耙、剁刀、柴刀、老煙斗、算盤、茶杯）轉換為符合 D&D 5E 規則的傷害骰 (1d8/1d10)、護甲值與專注施法道具。
  • 自然語言等級與狀態解析：支援輸入「大魔導師」對應 Lv.14、「老兵」對應 Lv.5；支援輸入「被封印狀態」自動啟動警告標籤並限制可用法術位。
  • 直向快速掃視角色卡 (Vertical Quick-Scan Card)：專為跑團備戰設計的垂直條列排版，讓 DM 在 3 秒內掌握角色身分、骰點、武器、解鎖能力與劇情伏筆。

二、 給誰用 (Who)

  • TRPG 地下城主 (Dungeon Master / Game Master)：徹底解決「玩家臨時搭話突發詢問」與「突發戰鬥需要即時數值」的備戰焦慮，備戰時間縮短 90% 以上。
  • 跑團玩家 (Roleplayers)：快速產生具有故事溫度與家族牽絆的隨從、導師或宿敵背景。
  • 奇幻小說家與獨立遊戲劇本創作者：快速豐富世界觀中的市井群像與各階層強者，兼具真實感與數值邏輯。

三、 怎麼做 (How)

本專題採用模組化分層架構，堅持採用 Python 3.12 純標準函式庫 開發，達成零外部依賴、極致輕量、即開即用與離線安全的特性。

核心模組設計

模組檔名 核心職責與設計理念
roller.py 4d6dl1 真隨機擲骰引擎、調整值計算器、職業核心主副屬性推薦配置演算法。
database.py D&D 5E 繁體中文標準資料庫（12 職業、9 種族、10 背景、1~20 等特長庫、非典型武器庫、故事生活法器庫）。
generator.py 故事與數值解耦核心、自然語言等級/封印解析、非典型裝備適配、預設凡人特質引擎。
exporter.py 直向快速掃視預覽卡生成、JSON 結構化匯出、官方 10 頁 Excel 模板扁平化對接字典。
main.py CLI 命令列入口、Windows UTF-8 終端機編碼容錯處理、單行參數快速生成介面。

四、 怎麼測 (How it's tested)

本專案進行了多場景、極端邊界與非典型角色的嚴密實測：

測試案例一：非典型農夫戰士（退隱禁衛長手持鋼齒長草耙）

python -m dnd_npc_generator.main --class-name "戰士 (Fighter)" --story "老丹恩，表面上只是個鄉村麥農，但真實身分是退隱多年的王國禁衛長，戰鬥定位是戰士，武器是一柄隨身的鋼齒草耙"

驗證結果：

  • 成功辨識草耙，自動配置【鋼齒長草耙】，傷害骰 1d8 (雙手 1d10) 穿刺，附帶多用與推撞備註。
  • 成功實擲 4d6dl1 點數池 [16, 14, 12, 11, 8, 8]，智慧建議力量 16 (+3)、體魄 14 (+2)，並附帶矮人種族加值候選清單供自主調配。
  • 特質自動維持「常規市井人物/普通冒險者」，展現凡人老兵的內斂氣質。

測試案例二：以老煙斗施法之十四環大魔導師

python -m dnd_npc_generator.main --class-name "法師 (Wizard)" --level "14" --story "隱居在迷霧森林邊界的神秘老學者，不使用常規魔杖，施法時總是抽著一支刻印符文的石楠木老煙斗"

驗證結果：

  • 精確解鎖至 Lv.14，包含熟練加值 +5、奧術回想等 14 等法師晉升特長。
  • 法器欄位成功替換為【刻印符文石楠木老煙斗】。
  • 法術位精準對齊 1~7 環（4/3/3/3/2/1/1）。
