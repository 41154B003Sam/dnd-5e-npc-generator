# 🎲 D&D 5E 劇情導向非典型 NPC 智慧生成系統
*(TRPG Story-Driven Unorthodox NPC Generator)*

[![Python 3.10+](https://img.shields.io/badge/python-3.10+-blue.svg)](https://www.python.org/downloads/)
[![D&D 5E Compatible](https://img.shields.io/badge/D&D%205E-Compatible-red.svg)](https://dnd.wizards.com/)
[![Zero External Dependencies](https://img.shields.io/badge/Dependencies-Zero%20(Standard%20Lib)-success.svg)](#)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

專為 **桌上角色扮演遊戲（TRPG / D&D 5E）** 地下城主（DM / Storyteller）設計的劇情向 NPC 智慧生成引擎。  
**核心理念**：規則是用來約束玩家的平衡性，而 NPC 是 DM 推動劇情的資產。本專案將「故事生活身分」與「戰鬥底層數值」徹底解耦，支援非典型生活武器（如鋼齒長草耙）、生活故事法器（如刻印符文石楠木老煙斗），並提供真隨機 4d6dl1 屬性建議池、**全 13 職業與子職業範型流派（含階層等級解鎖）**、**51 種繁中全背景庫**與專為跑團主持設計的**直向快速掃視角色卡 (Vertical Quick-Scan Card)**。

## 🔒 資安與合規聲明 (Security Statement)

本專案嚴格遵循學術與開源資安規範：
- 程式庫、截圖、文件與範例中**絕無包含**任何 API 金鑰、通行碼、存取權杖、Google Apps Script Web App 執行網址或任何真實機密。
- 本專案倉儲名稱 (`dnd-5e-npc-generator`) 不包含任何學生姓名或學號。
- 遵循「非主動不請求」原則：程式啟動或載入範本時**零呼叫、零消耗**，使用者主動點擊按鈕才調用，並即時透明顯示 Token 消耗與預估費用。
- 支援雙引擎架構：
  - **Gemini AI 智慧敘事引擎**：動態讀取環境變數或本地 `.env` 之 API Key，調用 Gemini 旗艦大語言模型創作深度身世、子職業哲學融入、反差言行小動作與 5E 生活武器適配。
  - **純本地離線備用引擎**：未連網或無 API Key 時自動無縫切換為純 Python 標準函式庫離線運作，保證任何情境皆可穩定使用。

## 🚀 快速展示演示（打開什麼、做什麼、看到什麼）

本系統提供 **全圖形化免終端機介面**（雙擊即開）與 **高階 CLI 命令列** 多種使用方式：

### 🖥️ 方式一：網頁圖形化版（最直觀、最推薦！）
1. **打開什麼？**  
   直接在資料夾雙擊 **`點我開啟網頁版.bat`** 或直接以瀏覽器點開 **`index.html`**。
2. **做什麼？**  
   挑選種族、職業、子職業範型（等級變動時即時更新可選範型清單），或在下方劇情欄位輸入一句話（例如：*「守墓人摩斯，挖墳鐵鎬，死靈法師」*），點擊 **【🎲 立即智慧生成 NPC 角色卡】**。
3. **看到什麼？**  
   畫面右側立即呈現精美的直向角色卡，呈現非典型裝備、真隨機 4d6dl1 點數池、範型解鎖特性與劇本推進線索，支援一鍵複製、列印 / PDF 與匯出 CSV / JSON！

---

### 💻 方式二：桌面原生視窗版
1. **打開什麼？**  
   雙擊 **`點我啟動桌面程式.bat`**（或無黑窗版本 `點我啟動桌面程式(無黑窗).vbs`）。
2. **做什麼？**  
   在桌面視窗中調整參數（支援點擊「🌾 老農戰士」、「📜 封印老法師」、「⛏️ 守墓人」快速載入範本），點擊 **【🎲 立即生成非典型 NPC】**。
3. **看到什麼？**  
   視窗右側即時載入直向卡片，支援一鍵複製剪貼簿、一鍵匯出 CSV 試算表或 JSON 檔案。
